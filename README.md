# Orthoscheme polylogarithms

The original Wolfram Language implementation of orthoscheme polylogarithms used in my research on special functions and scattering amplitudes.

## Requirements

- Wolfram Language / Mathematica
- [PolyLogTools](https://gitlab.com/pltteam/plt)

Load PolyLogTools before evaluating `orthoscheme.m`.

## Contents

- `orthoscheme.m` — weighted-alphabet operations, polygon combinatorics, multiple-polylogarithm constructions, coproducts, and symbol calculations.
